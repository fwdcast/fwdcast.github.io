FORECAST está abierto a recibir comentarios de personas investigadoras, profesionales sanitarios, analistas, evaluadores y otros perfiles interesados en la evaluación económica de tecnologías sanitarias.

## Contacto

Para enviar comentarios o consultas sobre el proyecto, puede escribirse a:

[daniel.perez@utamed.es](mailto:daniel.perez@utamed.es)

## Qué tipo de feedback es útil

Durante la fase actual resultan especialmente útiles comentarios sobre:

- claridad del flujo de trabajo propuesto;
- tipos de datos que debería aceptar la herramienta;
- funcionalidades necesarias para revisar extrapolaciones de supervivencia;
- contenido mínimo que debería incluir el informe de resultados;
- formatos de exportación útiles para modelos farmacoeconómicos;
- posibles barreras de uso para perfiles sin conocimientos avanzados de programación.

## Privacidad de las aportaciones

Los comentarios recibidos se usarán para mejorar la herramienta y orientar las fases de consulta y desarrollo. Si se publica una síntesis de las aportaciones, se hará de forma agregada y sin identificar a personas concretas, salvo autorización expresa.
