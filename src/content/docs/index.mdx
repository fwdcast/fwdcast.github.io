## Qué es FORECAST

FORECAST es un proyecto de investigación orientado a desarrollar una herramienta abierta y gratuita para ajustar curvas paramétricas a datos de supervivencia y extrapolar horizontes temporales en evaluaciones farmacoeconómicas.

El proyecto responde a una necesidad práctica: muchos modelos de coste-efectividad necesitan resultados a largo plazo, mientras que los ensayos clínicos suelen tener seguimiento limitado. FORECAST busca hacer este proceso más accesible, trazable y reproducible.

## Estado del proyecto

El trabajo se organiza en cinco paquetes: conceptualización, consultas, desarrollo del núcleo estadístico, desarrollo de la interfaz y difusión científica. Esta web irá incorporando los materiales públicos conforme estén consolidados.

## Resultados esperados

- Una aplicación funcional para cargar datos individuales o agregados de supervivencia.
- Ajustes paramétricos y flexibles con indicadores de ajuste como AIC y BIC.
- Exportación de resultados para apoyar modelos de evaluación económica.
- Un informe que documente las decisiones de modelización y mejore la trazabilidad.
